# ResNet14 + CIFAR-10：类 Fig.8–10 实验指导

从 **[详细讲解与操作指导书](GUIDE.md)** 开始。

这份材料只围绕本次实验：解释三张图验证什么，给出 CrossSim 参数、运行命令、统计与判读方法，并对应课程记录表。不是整篇论文精读。

| 文件 | 用途 |
|---|---|
| [GUIDE.md](GUIDE.md) | 原理、逐图操作、版本差异、参数表、排错与报告方法 |
| [单项实验脚本](tools/run_experiment.py) | 同一预训练 ResNet14 下跑基线、量化、器件误差、保持、ADC、Rp、电流统计与 ADC 校准 |
| [绘图脚本](tools/plot_results.py) | 将真实 CIFAR-10 JSON 转成 PNG 与 CSV；拒绝把合成输入当实验数据 |
| [验证记录](VALIDATION.md) | 本次检查范围与未完成的正式实验 |
| `assets/` | 从用户提供论文渲染的原图与相关页，仅供本实验对照 |

所有命令从 **CrossSim 仓库根目录**执行，不从本文件夹执行。正式结果建议写到 `scratch/sim-work/`。

当前代码版本的 SONOS 拟合与目标论文存在来源差异，必须先读指导书的第 4 节。附带脚本默认采用当前 SONOS 编程/保持拟合与论文描述的 0.87% 比例读噪声，是已明确说明的课程方法复现方案，不宣称得到原论文相同的数值。
